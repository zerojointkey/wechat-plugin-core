================================================================================

1.1 洋葱模型中间件流转机制
--------------------------------------------------------------------------------
系统采用标准的洋葱模型（Onion Model）中间件架构，核心流转路径如下：

[微信消息] -> BotController.onMessage 
  -> ChatGPTBot.onMessage (基础过滤与上下文包装)
  -> PluginManager.execute (洋葱模型调度器)
    -> FilterPlugin (priority=1, 协议脏数据拦截)
    -> RenShePlugin (priority=5, 人设切换与系统提示词注入)
    -> ShiTuPlugin (priority=10, 图片缓存与附件关联)
    -> ShiJieShuPlugin (priority=15, 世界书背景知识检索注入)
    -> LLMPlugin (priority=99, 大模型请求与响应)
  -> ctx.reply 自动回复微信

核心暗号变量传递机制：
- ctx.session.meta.systemPrompt: 由 RenShePlugin 注入角色人设，由 ShiJieShuPlugin 追加世界书背景，最终由 LLMPlugin 读取并发送给大模型
- ctx.session.chatHistory: 由 RenShePlugin 管理角色专属历史记录隔离，由 LLMPlugin 读取并维护对话上下文
- ctx.session.meta.currentPersona: 当前激活的角色卡 ID
- ctx.session.meta.currentPersonaWorldInfo: 角色卡绑定的私设世界书 ID
- ctx.session.meta.currentGlobalWorldInfo: 全局锁定的世界观背景 ID
- ctx.attachments: 由 ShiTuPlugin 注入图片 Base64 数据，由 LLMPlugin 构造多模态请求

插件间严格遵循单向数据流，通过 ctx.session.meta 进行松耦合通信，未发现跨插件的强依赖或循环引用。

1.2 核心大模型请求驱动机制
--------------------------------------------------------------------------------
系统的 LLM 请求由 LLMPlugin.ts 驱动，依赖以下配置源（优先级递减）：
1. configs/llm.json (热重载配置文件，优先级最高)
2. .env 环境变量 (OPENAI_API_BASE_URL, OPENAI_API_KEY, LLM_MODEL, TEMPERATURE)

- Model: gemini-3.5-flash

LLMPlugin 采用标准 OpenAI 兼容接口（/chat/completions），通过 fetch 发送 POST 请求，支持：
- 单轮对话与多轮历史上下文维护
- 多模态图片输入（通过 ctx.attachments 传递 Base64 编码图片）
- 流式响应（当前未启用）
- 温度参数控制（默认 0.6）

请求构造流程：
1. 从 ctx.session.meta.systemPrompt 读取系统提示词（已由 RenShePlugin 和 ShiJieShuPlugin 预组装）
2. 附加 ctx.session.chatHistory（已由 RenShePlugin 隔离为当前角色专属历史）
3. 追加当前用户输入（文本或多模态内容）
4. 发送请求并解析响应
5. 将用户输入和助手回复追加到 chatHistory
6. 执行历史记录裁剪（保留最近 40 条）

  ```typescript
  private renderTemplate(template: string, variables: Record<string, any>): string {
    let result = template;
    for (const [key, value] of Object.entries(variables)) {
      const placeholder = `{{${key}}}`;
      const replacement = value !== undefined && value !== null ? String(value) : "";
      result = result.split(placeholder).join(replacement);

    return result;
  }
  ```
- 出现位置：RenShePlugin, ShiJieShuPlugin

- 重复度：约 70% 逻辑相同
